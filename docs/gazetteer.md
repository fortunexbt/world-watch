# Gazetteer and map data

`src/shared/gazetteer.json` is a worldwide extract of the GeoNames cities15000 dataset downloaded 21 October 2026: 34,174 places in 244 country codes, with 264,214 alternate names beside the primary names. Coordinates are locality centroids, never street accuracy. GeoNames data: [GeoNames attribution and dump terms](https://download.geonames.org/export/dump/readme.txt), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), source https://download.geonames.org/export/dump/cities15000.zip. Source is provided as-is; geographic ambiguity remains unresolved unless supplied country/admin context disambiguates it. No online geocoder or public Nominatim requests.

Each entry is one string, `geonameid|name|country|admin1|lat|lon|alternates`, with comma-separated alternates, because the file ships inside the server Worker bundle. Alternates keep every script GeoNames lists. The build drops alternates that only repeat the name in another case, lowercase Latin machine romanisations such as `pari`, `kiv` or `dka` (they match ordinary words and are not how sources write places), names without letters, and GeoNames concatenation glitches. Names of two characters or fewer, common in Chinese and Japanese, still identify a model place but cannot by themselves count as source support.

`src/shared/countries.json` lists country labels, approximate centroids, aliases and the `radius_km` of country-scope fallback pins. The 175 entries drawn in `public/countries.geojson` come from its Natural Earth properties (`LABEL_X`/`LABEL_Y` and every `NAME*` field except the numeric `NAME_LEN`); their radius is the distance from the label point to the farthest boundary vertex, capped at the legacy 250 km and never below the 8 km city radius. The other 70 ISO 3166-1 states and territories, such as Singapore, Hong Kong, Malta, Bahrain, the Maldives, Andorra, Liechtenstein, Monaco, San Marino and Vatican City, take names in the same languages from the Unicode CLDR data in Node's ICU, their GeoNames capital (or largest locality) as centre, and a radius covering every cities15000 locality of that state plus the 8 km city radius. Archipelagos with one large town, such as the Maldives or Tuvalu, therefore keep an 8 km radius around the capital. BV, HM, IO, TK and UM have no cities15000 locality and stay absent. None of the 70 has a polygon in `public/countries.geojson`: there is no offline source for one, and the app does not invent boundaries.

`public/countries.geojson` is Natural Earth 1:110m admin-0 countries, downloaded from the upstream natural-earth-vector repository on 21 October 2026. [Public domain terms](https://www.naturalearthdata.com/about/terms-of-use/). Boundary geography does not imply a political position or event danger assessment.

Rebuild both JSON files offline from an unzipped dump with `node scripts/gazetteer.mjs path/to/cities15000.txt`. Output is deterministic for a given dump and Node ICU version.

Bounding boxes are `[west, south, east, north]`. A box with west greater than east crosses the antimeridian, so `170,-25,-170,-10` covers Fiji. Watch-area polygon rings with an edge spanning more than 180 degrees of longitude are read the same way.

Street detail uses the public [OpenFreeMap dark vector style](https://openfreemap.org/quick_start/), with OSM/OpenMapTiles attribution. The configurable style URL is `VITE_MAP_STYLE`. No offline tile scraping. Bundled boundaries remain available when detail tiles cannot load.
